# Yasogami High - Matrícula (ficha V20 retrô)

1. Coloque seu logo em `public/logo.png` (sem ele aparece um letreiro WordArt). O botão "Imprimir" usa html2canvas via CDN (precisa de internet).
2. `node server.js` (ou `npm start`) e abra http://localhost:3000
3. As fichas enviadas ficam em `data/fichas.json`. O Narrador também pode ver em http://localhost:3000/api/fichas
